# Датасети та машинне навчання в проєкті

Цей файл допомагає узгодити **операційну систему** (Docker, Telegram, правила) і **експеримент ML для записки** — їх не можна змішувати без пояснення.

---

## 1. Дві різні «моделі» в роботі

### A. Tier 1 у робочому пайплайні (`app/analytics/ml_rf.py`)

- **Що робить:** класифікує запис на основі **табличних ознак** після `enrich_with_mock_metadata()` (вік акаунта, активність, ентропія імені, довжина тексту тощо).
- **На чому навчається:** на **синтетично згенерованих** векторах з правилами розмітки (PoC / MVP).
- **Обмеження:** це не повноцінне навчання на реальному корпусі коментарів Telegram з експертною розміткою «бот/людина».

### B. Експериментальна оцінка ML (`scripts/ml_evaluation_report.py`)

- **Що робить:** тренує моделі **TF-IDF + RandomForest / LogisticRegression** на **відкритих текстах новин** і будує метрики та графіки (accuracy, precision, recall, F1, ROC, confusion matrix).
- **На чому навчається:** один із відкритих наборів нижче (залежить від доступності архіву).
- **Зв’язок з темою диплому:** мітки датасету трактуються як **проксі**: «хибний текст новини» наближено відображається на клас `bot_propaganda`, «достовірний текст» — на `human_clean`. Це обґрунтовує застосування класифікаційних методів до задачі виявлення недостовірного контенту, але **не замінює** окремий датасит коротких соціальних коментарів.

Після кожного запуску скрипта актуальний знімок зберігається в `reports/ml_eval/dataset_card.md`.

## 2. Джерела даних для експерименту

### ISOT Fake News Dataset (основний варіант)

- **Посилання на архів:**  
  https://onlineacademiccommunity.uvic.ca/isot/wp-content/uploads/sites/7295/2023/03/News-_dataset.zip  
- **Файли в архіві:** `Fake.csv`, `True.csv`  
- **Зміст:** статті, позначені як хибні або правдиві (англійською; домен політичних/світових новин, типові роки збору — орієнтовно 2016–2017).  
- **Офіційний опис лабораторії:** сторінка ISOT / IMPACT (див. сайт UVic ISOT).

### Резервний набір (якщо архів ISOT не відкривається)

- **Посилання:**  
  https://raw.githubusercontent.com/lutzhamel/fake-news/master/data/fake_or_real_news.csv  
- **Поля:** `title`, `text`, `label` (`fake` / `real`).

## 3. Обробка та мапінг міток

1. Текст для моделі: `title + ". " + text`.  
2. Мапінг на класи системи (лише для експерименту в розділі 4):  
   - `fake` → `bot_propaganda`  
   - `real` / `true` → `human_clean`  
3. Викид рядків з `len(text) <= 30`.  
4. `train_test_split`: 80% / 20%, `stratify` по мітці, `random_state=42`.

---

## 4. Чому графіки можуть бути «надто хорошими»

На парах «fake / real» англомовних новин **лексика та стиль часто сильно розрізняються**; TF-IDF це добре відловлює. Тому високі ROC-AUC / F1 на цих графіках **не означають автоматично** ту саму якість на:

- коротких коментарях у Telegram,
- українській мові,
- іронії / сарказмі / нейтральних репостах.

Це треба явно написати в записку як **обмеження узагальнення** та напрям подальшої роботи (збір власного розміченого корпусу під задачу).

## 5. Як відтворити артефакти для розділу 4

З каталогу `backend`:

```bash
python scripts/ml_evaluation_report.py
```

Або в ізольованому середовищі (рекомендовано, якщо локальний Python нестабільний):

```bash
docker run --rm -v "$(pwd):/work" -w /work python:3.12-slim bash -lc \
  "apt-get update -qq && apt-get install -y -qq build-essential libxml2-dev libxslt1-dev \
   && pip install -q -r requirements.txt && MPLBACKEND=Agg python scripts/ml_evaluation_report.py"
```

Результати: `reports/ml_eval/*`.
